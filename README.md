# 劳有所获·职有底气｜大学生就业成长支持项目宣传网页

这是「劳有所获·职有底气」大学生就业成长支持项目的单页宣传网页。页面按“价值理念→服务范畴→落地践行→育人目标”组织，聚焦职业生涯规划指导与就业心理健康支持两大核心板块，介绍测评服务、心理支持、干预课程、解压游戏、科普文章和科普视频等项目内容。

## 本地预览

直接打开 `site/index.html` 即可浏览；如果需要测试复制按钮和滚动动画，可在 `site` 目录启动一个静态文件服务器。

## GitHub Pages 部署

仓库已配置 `.github/workflows/pages.yml`：推送到 `main` 分支后会自动把 `site/` 发布到 GitHub Pages。

第一次使用时，在 GitHub 仓库的 **Settings → Pages** 中将发布来源设为 **GitHub Actions**。之后每次更新 `site/` 内容并推送，页面都会自动更新。

页面中的图片来自当前项目已有的「经历翻译四格」素材包；没有新增外部图片依赖。文案使用自我觉察、职业图景、生涯路径、成长赋能、落地践行和就业适配心理等生涯规划专业表达，并明确测评不替代临床诊断、心理支持必要时进行专业转介。
