# 劳有心获成长局｜心航计划宣传网页

这是「劳有心获成长局」心航计划的单页宣传网页。页面按“项目理念→支持服务→成长路径→内容更新”组织，介绍测评服务、心理支持、干预课程、解压游戏、科普文章和科普视频等项目内容。

网页中的“心理测评”和“心理支持”体验参考项目工作区中的小程序 `新文科实践创业助手/miniprogram/pages/assessment/` 与 `新文科实践创业助手/miniprogram/pages/support/`：包含近期状态、学习与生活、支持需求三类测评方向，三道轻量题目、结果提示、心情选择、支持方式、干预课程和十分钟呼吸解压游戏。网页版同样保留“不替代临床诊断”和紧急情况求助提醒。

## 本地预览

直接打开 `site/index.html` 即可浏览；如果需要测试复制按钮和滚动动画，可在 `site` 目录启动一个静态文件服务器。

## GitHub Pages 部署

仓库已配置 `.github/workflows/pages.yml`：推送到 `main` 分支后会自动把 `site/` 发布到 GitHub Pages。

第一次使用时，在 GitHub 仓库的 **Settings → Pages** 中将发布来源设为 **GitHub Actions**。之后每次更新 `site/` 内容并推送，页面都会自动更新。

页面中的主要图片来自当前项目已有的「经历翻译四格」素材包；社交账号入口使用项目提供的小红书与抖音二维码图片。文案使用自我觉察、职业图景、生涯路径、成长赋能、落地践行和就业适配心理等生涯规划专业表达，并明确测评不替代临床诊断、心理支持必要时进行专业转介。
