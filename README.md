# 经历翻译四格｜宣传网页

这是「劳有所获·职有底气」项目的单页宣传网页，主题是把普通经历拆成“任务—行动—结果—能力”四格，并在十分钟内完成一次练习。

## 本地预览

直接打开 `site/index.html` 即可浏览；如果需要测试复制按钮和滚动动画，可在 `site` 目录启动一个静态文件服务器。

## GitHub Pages 部署

仓库已配置 `.github/workflows/pages.yml`：推送到 `main` 分支后会自动把 `site/` 发布到 GitHub Pages。

第一次使用时，在 GitHub 仓库的 **Settings → Pages** 中将发布来源设为 **GitHub Actions**。之后每次更新 `site/` 内容并推送，页面都会自动更新。

页面中的图片来自当前项目已有的「经历翻译四格」素材包；没有新增外部图片依赖。
