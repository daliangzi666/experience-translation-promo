# 就业导向大学生成长支持项目文案修订实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将宣传页从泛化的成长支持介绍，修订为面向高校大学生就业成长的官方项目文案，并按“价值理念→服务范畴→育人目标”形成递进结构。

**Architecture:** 保持现有 GitHub Pages 静态单页结构，不引入新框架。以首页首屏承载价值理念，以服务卡片承载职业生涯规划指导与就业适配心理支持两大板块，以流程和结尾段落承载实践落地、成长赋能与育人目标；保留现有暖色视觉与项目图片。

**Tech Stack:** HTML、CSS、原生 JavaScript、GitHub Actions Pages 部署。

## Global Constraints

- 文案聚焦大学生就业与职业发展，不再以泛化“解压”作为主叙事。
- 使用“自我觉察、职业图景、生涯路径、成长赋能、落地践行、就业适配心理”等生涯规划专业词汇。
- 逻辑结构固定为：先价值理念，再服务范畴，最后育人目标。
- 心理服务明确写为就业心理健康支持/就业适配心理支持，并保留非诊断、必要转介边界。
- 规避口语化和过强网络感，保留高校项目官方文案的人文温度。
